# Этап 4. Основные команды

Вариант 7. Java 17+, Swing. `ls` и `cd` теперь работают с VFS;
добавлены `wc`, `echo` и вспомогательная команда `pwd`.
Все пути относятся к дереву в памяти, команды ОС не вызываются.
Команды запуска ниже выполняются из корня проекта.

## Запуск

```sh
./run.sh --vfs examples/stage3/deep.csv
./scripts/demo-stage4.sh           # все поддерживаемые режимы, затем exit
./scripts/demo-stage4.sh missing   # первая ошибка останавливает скрипт
./scripts/test.sh
GUI_TESTS=1 ./scripts/test.sh       # включая настоящее окно Swing
```

## Режимы команд

| Команда | Поведение |
| --- | --- |
| `ls [-al] [--] [пути...]` | Отсортированные имена, каталоги с `/`; без пути текущая папка |
| `ls -a` | Включает скрытые имена и `.`/`..` |
| `ls -l` | Тип `d`/`f`, размер файла в байтах, имя; размер каталога 0 |
| `cd [путь]` | Переход в каталог; без пути и с `~` в корень |
| `cd -` | Вернуться в предыдущий каталог и напечатать путь |
| `pwd` | Абсолютный виртуальный путь |
| `wc [-lwcm] [--] файлы...` | Счётчики и имя; для нескольких файлов также `total` |
| `echo [-n] [аргументы...]` | Аргументы через пробел; `-n` убирает завершающий LF |
| `exit` | Закрыть окно; аргументы являются ошибкой |

`ls -al` и отдельные `-a -l` равнозначны; несколько путей имеют отдельные
заголовки. `--` позволяет передавать имена, начинающиеся с `-`.
Пути поддерживают `/`, `.`, `..`, повторные `/`, относительные пути и
`~/путь`. Промежуточные элементы обязаны существовать и быть каталогами;
`ls file/` и `ls file/..` отклоняются. Ошибка `cd` не меняет текущую папку.
Приглашение `user@host:/текущий/путь$` меняется после успешного `cd`.

`wc` по умолчанию печатает LF-строки, слова и байты в таком порядке.
Файл без последнего LF не добавляет строку. `-m` считает символы Unicode
(кодовые точки), `-c` считает байты. `-w` распознаёт пробелы Unicode.
Для слов/символов необходим UTF-8; двоичные файлы доступны с `-c`/`-l`.
Комбинации опций выводятся в порядке `l,w,m,c`. Чтение stdin не реализовано.

`echo` без аргументов выводит пустую строку. Опция `-n` распознаётся только
как первый аргумент; остальные строки выводятся буквально. Переменные,
конвейеры, перенаправления и раскрытие шаблонов не поддерживаются.

## Ошибки и стартовые сценарии

`examples/stage4/startup-success.txt` показывает все режимы таблицы,
Unicode, пути в кавычках, пустой/двоичный файлы, несколько файлов и `exit`.
Каждая ошибка вынесена в отдельный сценарий, поскольку выполнение
останавливается на первой ошибке. В конце каждого ошибочного сценария
есть `NEVER_EXECUTED`: эта строка не должна исполняться.

```sh
./scripts/demo-stage4.sh directory
./scripts/demo-stage4.sh binary
./scripts/demo-stage4.sh options
./scripts/demo-stage4.sh arguments
./scripts/demo-stage4.sh unknown
./scripts/demo-stage4.sh quotes
./scripts/demo-stage4.sh cd-file
./scripts/demo-stage4.sh wc-options
./scripts/demo-stage4.sh wc-arguments
./scripts/demo-stage4.sh empty-path
./scripts/demo-stage4.sh exit-arguments
```

После ошибки стартового скрипта окно остаётся открытым: попробуйте `ls`,
затем `exit`. Ошибки чтения VFS дают код процесса 3, конфигурации - 2.
Ошибки команд отображаются в терминале; GUI продолжает работу.

## Проверка и защита

`BasicChecks` проверяет вывод команд, навигацию, LF/слова/байты/Unicode,
двоичные и пустые файлы, `--`, ошибки и обновление приглашения.
`ScenarioChecks` исполняет все поставленные сценарии и проверяет остановку.
`GuiChecks` проверяет настоящее окно, ввод, историю, защиту вывода, очистку,
отмену, продолжение после ошибки и завершение через `exit`.

На защите: покажите `ls -al`, `cd /a/b/c`, `pwd`, `cd -`,
`wc hello.txt empty.txt`, `wc -c binary.bin`, `echo -n "текст"`,
ошибку `cd hello.txt` и последующее успешное выполнение `ls`.
